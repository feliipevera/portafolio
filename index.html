01 / sobre mí

Aprender a programar, paso a paso

Soy de Medellín y estoy construyendo mi camino como desarrollador web. Aprendo con retos pequeños: cada uno tiene un objetivo, una prueba y una bitácora donde anoto qué hice, qué falló y cómo lo corregí.

Mi proyecto principal es Rueda Libre, un sitio de alquiler de bicicletas en Medellín que fui construyendo por versiones: HTML semántico, tablas y formularios accesibles, CSS con variables, diseño mobile-first y, ahora, comparaciones con Bootstrap y Tailwind.

Vengo de la formación como tecnólogo en Mantenimiento de Automotores (SENA). De ahí traje un hábito que me sirve al programar: observar, aislar la falla, corregir y dejarlo documentado.

Mi método para resolver errores

  1. 1Observar: leo el error y miro la consola de DevTools.
  2. 2Aislar: pruebo una sola cosa a la vez hasta ubicar la línea.
  3. 3Corregir: hago el cambio más pequeño que lo arregle.
  4. 4Documentar: lo anoto en la bitácora y hago commit.

03 / bitácora de retos

Cómo fui construyendo Rueda Libre

Cada reto sumó una habilidad nueva. Así fue el recorrido:

  1. Estructura base y bitácora

    Carpetas organizadas (index.html, paginas, img) y un archivo de bitácora para documentar cada paso.

  2. Contenido semántico y tablas de tarifas

    Títulos jerárquicos, listas, enlaces e imágenes con alt, más tablas accesibles de tarifas y recorridos.

  3. Formulario de reservas y validación

    Campos con etiquetas, validación nativa (required, minlength, pattern) y pruebas con teclado documentadas en una tabla.

  4. CSS con variables y modelo de caja

    Paleta de marca, tipografías, escala de espaciado, herencia en DevTools y resolución de conflictos de especificidad sin !important.

  5. Mobile-first y GitHub Pages

    Diseño que parte del celular y crece con media queries; sitio publicado desde la rama principal.

  6. Bootstrap vs CSS propio

    Comparé la misma flota hecha a mano y con la grilla y utilidades de Bootstrap 5, midiendo tiempo, líneas de CSS y control perdido.
