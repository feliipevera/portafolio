# Portafolio | Duban Felipe Sarmiento Vera

Portafolio personal de un tecnólogo en Mantenimiento de Automotores (SENA) y desarrollador web en formación, en Medellín, Colombia.

## Tecnologías
- HTML5 semántico
- Tailwind CSS (CDN)
- Git y GitHub
- GitHub Pages

## Estructura
```
portafolio/
├── index.html
├── README.md
└── img/
    └── imagen1.jpg
```

## Cómo verlo en local
1. Clona el repositorio.
2. Abre la carpeta en VS Code.
3. Clic derecho en `index.html` → **Open with Live Server**.
